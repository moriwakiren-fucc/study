🎓 理論の詳細

1 コーナー座標の対応

射影変換は、元画像の4つのコーナーが、出力画像のどこにマッピングされるかを指定することで定義されます。

元画像: → 出力画像:
src[0] (x1,y1) → dst[0] (u1,v1)
src[1] (x2,y2) → dst[1] (u2,v2)
src[2] (x3,y3) → dst[2] (u3,v3)
src[3] (x4,y4) → dst[3] (u4,v4)

2 ホモグラフィ行列

ホモグラフィ行列 H は 3×3 行列で、同次座標系を使って点を変換します：

[u] [h₁₁ h₁₂ h₁₃] [x]
[v] = [h₂₁ h₂₂ h₂₃] [y]
[w] [h₃₁ h₃₂ 1 ] [1]

最終的な座標は (u/w, v/w) となります（同次座標の正規化）

3 行列の計算方法

4つのコーナー対応から、8×9 の線形方程式系を構築し、SVD（特異値分解）で解きます：

A · h = 0

ここで A は以下の形式：
A = [
-x₁ -y₁ -1 0 0 0 u₁x₁ u₁y₁ u₁
0 0 0 -x₁ -y₁ -1 v₁x₁ v₁y₁ v₁
-x₂ -y₂ -1 0 0 0 u₂x₂ u₂y₂ u₂
...
]

4 画像の再構成

出力画像のピクセル (u, v) に対して、元画像の対応する座標 (x, y) を逆マッピングで計算します：

[x] [u]
[y] = H⁻¹ · [v]
[1] [1]

元画像でのサンプリング位置 (x, y) が計算されます。
小数座標の場合は、周辺ピクセルから補間します。

5 補間方式

サンプリング位置が整数座標でない場合、複数の補間方式が使えます：

  • 最近傍補間 — 最も近いピクセルの値を使用（高速、低品質）
  • 双一次補間 — 4つの周辺ピクセルから線形補間（バランス型、推奨）
  • 双三次補間 — 16個のピクセルから補間（高品質、遅い）

6 実践例：文書スキャン

スマートフォンで斜めから撮影した書類を、自動的に正面ビューに補正する場合：

// 入力: 傾いた文書の4つのコーナー
src = [(x1,y1), (x2,y2), (x3,y3), (x4,y4)]

// 出力: 長方形
dst = [(0,0), (W,0), (W,H), (0,H)]

// ホモグラフィ行列を計算
H = getPerspectiveTransform(src, dst)

// 補正
result = warpPerspective(image, H, (W, H))

💡 重要なポイント

射影変換は、スマートフォンのスキャンアプリ、ドローン画像の補正、看板認識など、 カメラの視点角度を補正する際に広く使われています。4つのコーナーペアがあれば、 任意の台形を長方形に変換できます。左側のキャンバスを操作して、その効果を確認してください！
