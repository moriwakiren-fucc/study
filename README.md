ご提示いただいた全プリント（原子物理の各テーマ）に基づき、「何を求めるときにどう立式・計算するか」を網羅して体系化した一般化解法ガイドです。

## 1. トムソンの実験（比電荷の測定）

> **立法の解法方針**：等加速度運動・放物運動・ローレンツ力の釣り合いを、直交座標系（水平・鉛直）ごとに分けて処理する。
> 
> 

* **加速直後の速さ $v_0$ を求めるとき**
エネルギー保存則より：

$$e V_0 = \frac{1}{2} m v_0^2 \implies v_0 = \sqrt{\frac{2 e V_0}{m}}$$


* **偏光板（電場）通過時の軌道・偏位 $Y$ を求めるとき**
* $x$ 方向（水平）：速さ $v_0$ の等速直線運動（通過時間 $t_1 = \frac{l}{v_0}$）。


* $y$ 方向（鉛直）：加速度 $a = \frac{eE}{m}$ の等加速度運動。


* 板通過後の偏位 $Y$ は、**板内部での放物運動の変位 $y_1$** と **板外での等速直線運動の変位 $y_2$** の和で表す：



$$Y = y_1 + y_2 = \frac{e E l^2}{2 m v_0^2} + \frac{e E l L}{m v_0^2} = \frac{e E l}{m v_0^2}\left(L + \frac{l}{2}\right)$$




* **磁場を加えて「電子を直進（無偏向）」させるとき**
電場による力 $eE$ とローレンツ力 $e v_0 B$ の釣り合いを立てる：



$$e E = e v_0 B \implies v_0 = \frac{E}{B}$$



（※ 磁場の向きはフレミングの左手の法則で決める。電子は負電荷なので**電流は進む向きと逆**）。

## 2. ミリカンの油滴実験（電気素量の測定）

> **立法の解法方針**：荷電粒子の「速度一定（終端速度）」の条件から、運動方向ごとの力の釣り合い式をつくる。
> 
> 

* **電場なしで終端速度 $v_1$ で落下するとき**

$$\text{重力 } m g = \text{空気抵抗 } k r v_1$$


* **電場 $E = \frac{V}{d}$ を加えて終端速度 $v_2$ で上昇するとき**

$$\text{静電気力 } q E = \text{重力 } m g + \text{空気抵抗 } k r v_2 = m g \left(1 + \frac{v_2}{v_1}\right)$$


* **複数データの測定値から電気素量 $e$ を決めるとき**
1. 測定値どうしの「差」を計算し、その最小公約数からおおよその $e \approx 1.6 \times 10^{-19} \text{ C}$ を推定する。


2. 各測定値が $e$ の何倍（整数 $n_i$）かを決定する。


3. 全測定値の合計を全整数の合計で割って平均化する：



$$e = \frac{\sum q_i}{\sum n_i}$$

## 3. 光電効果

> **立法の解法方針**：光子1個と電子1個の「1対1のエネルギー授受」としてエネルギー保存を立てる。
> 
> 

* **基本方程式（光電方程式）**

$$h \nu = K_{\text{max}} + W \quad \left(\text{波長表示なら } \frac{hc}{\lambda} = K_{\text{max}} + W\right)$$


* **阻止電圧 $V_0$ を求めるとき・与えられたとき**

$$K_{\text{max}} = e V_0 \implies e V_0 = h\nu - W$$


* $V_0$–$\nu$ グラフの**傾き**は $\frac{h}{e}$、**横軸切片**は限界振動数 $\nu_0 = \frac{W}{h}$ を表す。




* **飽和電流 $I_0$ を求めるとき**
1秒あたりの光子のエネルギー総量 $P$ から光子数 $N = \frac{P}{h\nu}$ を求め、$I_0 = N e$ とする。

## 4. X線の発生・特性とブラッグ反射

> **立法の解法方針**：発生はエネルギー変換（連続X線）または順位遷移（固有X線）、回折は波の干渉で求める。
> 
> 

* **連続X線の最短波長 $\lambda_{\text{min}}$ を求めるとき**
電子の運動エネルギーがすべて1個の光子に変わるとき：



$$e V = h \nu_{\text{max}} = \frac{hc}{\lambda_{\text{min}}} \implies \lambda_{\text{min}} = \frac{hc}{eV}$$


* **ブラッグの反射条件（結晶での強い反射）**

$$2 d \sin\theta = m \lambda \quad (m = 1, 2, 3, \dots)$$


* $\theta$ は「格子面とX線がなす角」（入射角・反射角ではない点に注意）。


* 観測可能な最大の次数 $m_{\text{max}}$ を求める際は、$\sin\theta \le 1$ より $m \le \frac{2d}{\lambda}$ を満たす最大の整数を選ぶ。

## 5. コンプトン効果

> **立法の解法方針**：光子と電子の「2次元弾性衝突」として、運動量保存（$x, y$ 成分）とエネルギー保存を連立する。
> 
> 

1. **保存則の立式**
* $x$ 方向運動量保存：$\frac{h}{\lambda} = \frac{h}{\lambda'} \cos\theta + m v \cos\phi$

* $y$ 方向運動量保存：$0 = \frac{h}{\lambda'} \sin\theta - m v \sin\phi$

* エネルギー保存：$\frac{hc}{\lambda} = \frac{hc}{\lambda'} + \frac{1}{2} m v^2$



2. **電子の角度 $\phi$ と速度 $v$ を消去するパターン処理**
* 運動量の2式から $m v \cos\phi$ と $m v \sin\phi$ の形にし、2乗して足して $\cos^2\phi + \sin^2\phi = 1$ を適用し $\phi$ を消去。


* エネルギーの式より $m v^2 = 2 hc \left(\frac{1}{\lambda} - \frac{1}{\lambda'}\right)$ と変形し、上の式と比較して $v$ を消去。


* 近似式（$\frac{\lambda'}{\lambda} + \frac{\lambda}{\lambda'} \approx 2$ など）を用いて波長変化を導出：



$$\lambda' - \lambda = \frac{h}{m c} (1 - \cos\theta)$$

## 6. 物質波（ド・ブロイ波）と電子線回折

> **立法の解法方針**：粒子を「波長 $\lambda = \frac{h}{p}$ の波」として扱い、結晶による干渉条件を立てる。
> 
> 

* **加速電圧 $V$ で加速された粒子のド・ブロイ波長 $\lambda$**

$$e V = \frac{1}{2} m v^2 \implies p = m v = \sqrt{2 m e V} \implies \lambda = \frac{h}{\sqrt{2 m e V}}$$


* **電子線回折の強め合い条件**
ブラッグ反射とまったく同じ条件式をつくる：



$$2 d \sin\theta = n \lambda \quad (n = 1, 2, 3, \dots)$$

## 7. 光子気体と光の圧力

> **立法の解法方針**：熱力学の「気体分子運動論」の解法ステップを光子の運動量・エネルギーに置き換える。
> 
> 

1. **壁1回反射の力積**：$I = 2 p_x = 2 \left(\frac{h\nu}{c}\right) \cos\theta$

2. **時間の平均化**：往復時間 $\Delta t = \frac{2 L}{c_x}$ より、1個の光子が及ぼす力 $f = \frac{p c_x^2}{L c}$

3. **等方性の適用**：$\overline{c_x^2} = \overline{c_y^2} = \overline{c_z^2} = \frac{1}{3} c^2$

4. **全体の圧力 $P$ の算出**：

$$P = \frac{N \bar{f}}{L^2} = \frac{N h \nu}{3 V} = \frac{1}{3} u \quad (\text{※ 単位体積エネルギー } u = \frac{N h \nu}{V})$$



（※ 気体分子運動論の $P = \frac{2}{3} u$ との違いに注意）。

## 8. $\alpha$ 粒子の散乱と原子核

> **立法の解法方針**：静電気力のみを受ける運動として「エネルギー保存則」を立てる。
> 
> 

* **正面衝突での最近接距離 $r_{\text{min}}$ を求めるとき**
最も近づいた瞬間は速さが一瞬 $0$ になるため：



$$\text{初めの運動エネルギー } K = \text{位置エネルギー } \frac{k (2e) (Ze)}{r_{\text{min}}} \implies r_{\text{min}} = \frac{2 k Z e^2}{K}$$

## 9. ボーアの原子模型とスペクトル系列

> **立法の解法方針**：「運動方程式」「量子条件」「振動数条件」の3つを連立する。
> 
> 

1. **等速円運動の運動方程式**：$\frac{m v^2}{r} = \frac{k e^2}{r^2}$

2. **量子条件**：$2 \pi r = n \lambda = n \frac{h}{m v} \implies m v r = n \frac{h}{2\pi} \quad (n = 1, 2, 3, \dots)$

* 1 と 2 より、軌道半径 $r_n \propto n^2$、エネルギー準位 $E_n = -\frac{R h c}{n^2}$ を導く。




3. **振動数条件（光子放出・吸収）**：

$$h \nu = \frac{h c}{\lambda} = E_{n_2} - E_{n_1} \implies \frac{1}{\lambda} = R \left( \frac{1}{n_1^2} - \frac{1}{n_2^2} \right) \quad (n_2 > n_1)$$


* **ライマン系列**：$n_1 = 1$ （紫外線）


* **バルマー系列**：$n_1 = 2$ （可視光）


* **パッシェン系列**：$n_1 = 3$ （赤外線）





* **イオン化エネルギー（電離エネルギー）**
基底状態（$n = 1$）の電子を無限遠（$n = \infty, E_\infty = 0$）まで取り去るエネルギー：

$$\Delta E = 0 - E_1 = R h c \quad (\approx 13.6 \text{ eV})$$
